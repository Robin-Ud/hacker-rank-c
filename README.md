# HackerRank em C

Minhas soluções da trilha de C do [HackerRank](https://www.hackerrank.com/domains/c),
feitas enquanto aprendo a linguagem. Um arquivo por exercício, na ordem em que resolvi.

| # | Exercício | Assunto |
|---|---|---|
| 01 | Functions in C | funções |
| 02 | Pointers in C | ponteiros |
| 03 | Printing Pattern Using Loops | laços aninhados |
| 04 | Conditional Statements in C | `if` / `else` |
| 05 | For Loop in C | `for` |
| 06 | Sum of Digits of a Five Digit Number | `%` e `/` (o `06a` é uma segunda versão) |
| 07 | Bitwise Operators | operadores bit a bit |
| 08 | 1D Arrays in C | `malloc` e vetores |
| 09 | Array Reversal | ponteiros em vetores |
| 10 | Printing Tokens | strings com `strtok` |

```bash
gcc 02_Pointers_in_C.c -o ex && ./ex
```
